# Checkingo Releases

This repository contains official APK releases for the Checkingo application.

## Purpose

This repository is dedicated to storing and distributing Android APK files for Checkingo app releases only. All release APKs are stored here for easy access and download.

## Release Structure

Each release includes:
- APK file (`.apk`)
- Release notes describing changes and updates

## How to Download

1. Navigate to the [Releases](../../releases) page
2. Find the desired version
3. Download the APK file from the release assets

## Installation

1. Download the APK file from the desired release
2. Enable "Install from Unknown Sources" in your Android device settings
3. Open the downloaded APK file
4. Follow the installation prompts

## Security Notice

Always download APK files only from official releases in this repository. Verify the release source before installation.

## Support

For issues or questions about Checkingo, please refer to the main application repository.
